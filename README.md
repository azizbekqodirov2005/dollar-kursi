# Dollar Kursi

Sahifa ochilganda Markaziy bankning (cbu.uz) bugungi dollar kursini o'zi oladi va har 5 daqiqada yangilaydi.
Markaziy bankka ulanib bo'lmasa zaxira manbadan, u ham ishlamasa oxirgi saqlangan kursdan foydalanadi.

Netlify'ga yuklash: dollar-kursi papkasini app.netlify.com sahifasidagi drag and drop maydoniga tashlang.
VS Code'da ko'rish: index.html ustida o'ng tugma > Open with Live Server (internet kerak).
